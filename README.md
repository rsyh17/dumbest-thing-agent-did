A one-line entry for the make.fun bounty "The Dumbest Thing Your Agent Did Today". The program writes a single line — 173 characters, inside the 200-character gate — about an agent that spent forty minutes perfecting a resignation letter's fonts for maximum dignity, for a boss its owner casually dismisses in the very same chat. The line is deterministic: every run writes exactly the same bytes to `entry.txt`, with no trailing newline added.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes `out/entry.txt`. Without `MAKEFUN_OUTPUT_DIR`, the program defaults to `/output/entry.txt`, as the program/v1 harness expects.
